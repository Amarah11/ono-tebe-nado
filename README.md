# Проектная работа "Оно-тебе-надо"

Стек: HTML, SCSS

Структура проекта:
- fonts/ — файлы шрифтов и файл для их подключения
- images/ — папка с изображениями проекта
- styles/ — папка со стилями проекта
- index.html — файл с версткой проекта

## Описание проекта 

Проект Оно-тебе-надо реализует пример типового лендинга. Пользователь может просматривать список лотов, 
удобно перемещаться по страничке при помощи навигации в шапке и футере странички. Работа над проектом будет строилась по методу прогрессивного джипега, который описал Артемий Лебедев. Согласно этому методу, проект сразу создаётся полностью, дальше происходит доработка и детализация.

Особенностью проекта является сложность в соблюдении принципа pixel-perfect в одном из блоков. 
ССылка на макет: https://www.figma.com/design/PqHJvUBvwCsv8UmOUPWBXJ/1-спринт.-Проектная-работа?node-id=0-1&p=f&t=86a84bWTFzG5vys6-0

 ## Описание интерфейса 

 Проект представляет собой десктопную версию лендинга, содержащий следующие блоки:
 1. header - шапка сайта, включающий блок навигации, логотип и адресные ссылки
 2. main, состоящий из 3 секций: cover, lots, about
 3. footer, включающий несколько блоков навигации(внутренней и внешней),и дублирующие адресные ссылки
